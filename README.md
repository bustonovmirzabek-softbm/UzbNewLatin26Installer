Loyihа hаqidа
     Uşbu repozitoriy Windows platformаsi uçun 2026 yilgi yangi özbek lotin аlifbosigа аsoslаngаn mахsus klаviаturа rаsklаdkаsini örnаtish fаyllаrini öz içigа olаdi.
     Xususiyatlаri:
     Yangi аlifbo tаlаblаrigа töliq mos kelаdi.
     Quyidagi mахsus hаrflаrni qulаy kiritiş imkoniyati mаvjud:
     Ğ ğ
     Ö ö
     Ş ş
     Ç ç
     Örnаtiş tаrtibi:
    1.	Arxivini yuklаb oling vа oçing.
    2.	“Uzb new latin-installer.exe” fаylini işgа tuşiring.
    3.	Windows tizimining til sozrlаmаlаridаn yangi klаviаturаni tаnlаng.
   
  Лойиҳа ҳақида
     Ушбу репозиторий Windows платформаси учун 2026 йилги янги ўзбек лотин алифбосига асосланган махсус клавиатура раскладкасини ўрнатиш файлларини ўз ичига олади.
    Хусусиятлари:
     Янги алифбо талабларига тўлиқ мос келади.
     Қуйидаги махсус ҳарфларни қулай киритиш имконияти мавжуд:
     Ğ ğ
     Ö ö
     Ş ş
     Ç ç
  Ўрнатиш тартиби:
       1. Архивини юклаб олинг ва очинг.
       2. `Uzb new latin-installer.exe` файлини ишга туширинг.
       3. Windows тизимининг тил созламаларидан янги клавиатурани танланг.
      
  О проекте
     Данный репозиторий содержит установочные файлы специальной раскладки клавиатуры для Windows, основанной на новом узбекском латинском алфавите 2026 года.
     Особенности:
     Полностью соответствует требованиям нового алфавита.
     Обеспечивает удобный ввод следующих специальных букв:
     Ğ ğ
     Ö ö
     Ş ş
     Ç ç
     Порядок установки:
     1. Скачайте и распакуйте архив.
     2. Запустите файл “Uzb new latin-installer.exe”.
     3. Выберите новую раскладку клавиатуры в языковых настройках Windows.
     
  About the Project
     This repository contains the installation files for a custom Windows keyboard layout based on the new Uzbek Latin alphabet for 2026.
     Features:
     Fully compliant with the new alphabet standards.
     Provides convenient typing for the following special characters:
     Ğ ğ
     Ö ö
     Ş ş
    Ç ç
    Installation Instructions:
    1. Download and extract the archive.
    2. Run the "Uzb new latin-installer.exe" file.
    3. Select the new keyboard layout in the Windows language settings.
